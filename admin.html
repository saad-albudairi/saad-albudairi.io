تسجيل الدخول 🔐

الصق مفتاح GitHub الخاص بيك. ما ينرسل لأي مكان غير GitHub، وينمسح من تسد المتصفح إلا إذا فعّلت «تذكرني».

شلون أسوي المفتاح؟ (مرة وحدة بس)
  1. ادخل على GitHub بحسابك، وافتح: صفحة إنشاء المفتاح
  2. Token name: اكتب saad admin
  3. Resource owner: اختار saad-albudairi
  4. Expiration: اختار سنة (أو No expiration)
  5. Repository access: اختار Only select repositories، وبعدها saad-albudairi.io
  6. Permissions ← Repository permissions ← Contents: اختار Read and write
  7. اضغط Generate token، انسخ المفتاح والصقه هنا

لا تنطي المفتاح لأحد. اللي عنده المفتاح يگدر يغيّر الموقع.

📊 الزيارات وتحليل الزباين

الموقع يحسب: عدد الزوار، منين جايين (Google، الستيكر، فيسبوك)، أي موبايل، أكثر الأقسام، أكثر القياسات اللي تنضاف للسلة وتنطلب، والطلبات من يا محافظة.

📈 افتح لوحة الإحصائيات أول مرة؟ سجّل حساب
شلون أشغّل الإحصائيات؟ (مرة وحدة بس)
  1. اضغط «أول مرة؟ سجّل حساب»
  2. بخانة Code اكتب بالضبط: saad-albudairi
  3. اكتب إيميلك وكلمة سر، واضغط Sign up
  4. بعدها «افتح لوحة الإحصائيات» تطلعلك كل الأرقام

شلون تقرا اللوحة: Pages = الأقسام والطلبات (اللي تبدي بـ «طلب/» و«سلة/» هي طلبات الزباين)، Referrers = منين جايين، Locations = الدول، Browsers / Systems = نوع الأجهزة.

التغييرات توصل للموقع بعد دقيقة تقريباً.
